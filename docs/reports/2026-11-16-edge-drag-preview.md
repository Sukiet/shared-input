# 屏幕边缘拖拽对象本地验证

基线 b9d5a66。当前实现是 Windows 本地测试，用于验证屏幕边缘能否通过系统 OLE 回调取得拖拽文件列表，不实现传输或跨设备接管。

## 使用

控制端按键例外下方增加“边缘拖拽测试”。手动开启后，在主显示屏、显示屏布局设置所选的边缘建立完全无绘制、宽度仅 1 个物理像素的接收窗口。将资源管理器中的文件或文件夹拖到屏幕最外侧，界面显示名称、完整路径、数量和源对象提供的数据格式。无需松手，列表在 DragEnter 时读取；离开后保留最后结果，支持清空。

该窗口不激活、不抢焦点，不属于主窗口的拥有窗口，所以单独最小化主窗口不会按拥有关系隐藏接收条。平时使用空窗口区域，普通鼠标移动、点击和滚轮直接命中下方应用；按住左键或右键并超过系统拖动阈值后，才打开最外侧 1 像素的命中区域，松开后关闭。手势仅用于判断何时启用接收区域，不会把任意按住移动都认作文件；真正的对象身份仍由 OLE 回调确认。手动关闭测试或退出应用会撤销注册并销毁窗口。

测试默认关闭，开启状态和文件列表不持久化；切换到被控端或重新初始化时关闭。测试开启期间原生和界面都禁止开始控制，并暂停正常边缘切换；关闭后恢复原有控制条件。已连接的音频等通道不参与测试处理。

界面实时显示原生命中区域的开关状态：灰色“区域关闭（鼠标穿透）”或绿色“区域打开（1 像素命中）”；测试未开启时显示“区域关闭（测试未开启）”。状态来自 SetWindowRgn 成功后的原生反馈，仅在实际开关变化时发送，不依赖 Dart 推测鼠标状态。屏幕边缘仍保持不可见。

## 边界

- 使用 OleInitialize、RegisterDragDrop 和 IDropTarget，读取源 IDataObject。仅枚举数据格式、读取 CF_HDROP 路径列表，或 FileGroupDescriptorW 虚拟文件名称描述。
- 不读取 FileContents、不创建/修改文件、不把内容写入剪贴板或网络。拖拽回调始终返回 DROPEFFECT_NONE，拒绝复制或移动；禁止放置光标属于预期行为，源端不会收到成功移动确认。
- 普通文件和文件夹只显示路径，不查询磁盘文件属性。虚拟文件只显示名称并标记“待生成”，不会请求生成实际内容。其他对象显示不支持及可用格式。
- 元数据上限 16 MiB，最多显示 256 项，保留可解析列表的实际数量和截断提示。检查缓冲区偏移、长度、终止符及虚拟文件计数，非法数据不展示部分结果。
- 在主原生 STA 消息线程注册和注销 OLE；DragOver 只回复效果，不高频向 Flutter 发事件。文件列表使用带序号的快照，关闭后的旧消息不能重新开启测试；关闭或重新开启后的重入元数据结果通过代数检查丢弃。
- 使用 WS_EX_NOREDIRECTIONBITMAP 不创建可见绘图表面，也不画背景或文字；不通过 alpha=1 模拟透明。隔离原生试验中，1 物理像素接收窗口的背景像素保持不变，且能收到真正的 DoDragDrop 回调；alpha=0 的分层窗口则无法收到回调。普通 WS_EX_TRANSPARENT / HTTRANSPARENT 不能同时满足跨应用鼠标穿透与 OLE 命中，未依赖这两种方式。
- 拖动手势通过既有原生鼠标钩子只读观察，按下及松开原样放行，达到阈值和释放时各投递一次原生消息；不逐帧通知 Dart、不模拟鼠标消息、不增加高频轮询。消息带接收窗口代数，关闭后不接受旧手势激活。
- 在其他种类的按住拖动（例如窗口或文本拖动）期间，该 1 像素也可能被启用，因此不声称对所有应用的所有拖动都零影响。
- 这一步只验证接住源对象。原生拖拽会话的跨机交接、目标端创建拖拽会话和真正接收文件均未实现，Mac 端测试接收条也未实现。

## 验证

原生测试覆盖中文路径、多文件和文件夹路径、虚拟文件名称、超长列表截断、非法偏移和计数；调用真实 IDataObject/IDropTarget 接口验证只读元数据且所有阶段拒绝复制/移动。另在本机创建并成功注册真实 OLE 接收窗口，验证不抢焦点及关闭后窗口销毁。界面测试覆盖显示/保留/清空列表、暂停控制、注册失败、过期消息、角色切换与重新启动默认关闭。

静态分析无问题，83 项 Flutter 测试、12 项 Windows 原生测试全部通过，Windows Debug 已构建并启动。原 24 DIP 可见版已由用户确认能显示实际文件列表；透明 1 像素、动态命中版本也已获用户实测确认：“能识别，普通点击正常”。此结果对应当前机器及此次操作，不代表所有来源应用都已验收。

仍需用资源管理器进行实际拖拽：开启后拖单文件、多选和文件夹到配置屏幕边缘最外侧的 1 像素，核对界面列表；拖离后或按 Esc 取消，源文件应保持原状，关闭测试后不再记录新的拖拽。若不识别，记录来源应用与显示的数据格式。
